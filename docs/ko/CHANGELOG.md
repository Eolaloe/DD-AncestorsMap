# 변경 내역

Ancestor's Map의 주요 변경 사항을 기록합니다. 버전 번호는 `주.부.수정` 형식이며, 날짜는 한국 시간(UTC+9) 기준입니다.
[Keep a Changelog](https://keepachangelog.com/ko/1.1.0/) 형식을 따르며, 새 기능, 개선, 버그 수정으로 나눕니다.

1.0.0·1.0.1·1.1.1은 공개 릴리스가 없으며, 첫 공개 릴리스는 1.0.2입니다.

## [1.3.3] - 2026-11-02

### 개선

- 일부 UI 배치 변경

## [1.3.2] - 2026-11-01

### 새 기능

- **건물 창 넘기기**: 건물 창에서 Q · E 또는 새 버튼으로 이전·다음 건물로 이동합니다. 잠긴 건물은 건너뛰며, 버튼은 창이 열리고 전환되는 연출을 따라 움직입니다.
- **골동품 앞 자동 전환**: 원정대에 유물수집상이나 골동품 추가 획득 특성이 있는 모드 영웅이 있으면, 전리품이 나올 수 있는 골동품 앞에서 해당 영웅을 자동으로 선택합니다. 탐험 중 해당 영웅의 체력 막대 옆 토글로 켜고 끕니다.
- **속도 설정(배속모드)**: 오버레이 사이드 패널 맨 앞 버튼에서 전진·후진·전투·정찰 속도를 각각 조정합니다. 초기화하거나 앱을 종료하면 원래 값으로 복원합니다.

### 개선

- **적 정보 스포일러 방지**: 지도 아래 전투 아이콘으로 적 정보를 끄면, 이미 지나온 복도에 새로 생긴 전투의 적 구성도 직접 맞서기 전까지 숨깁니다.
- **장신구 프리셋**: 프리셋 적용 후 마우스 커서가 장신구 가방의 닫기 버튼으로 이동합니다.
- **마을 미터기**: 마을에 들어올 때 잠깐 펼쳐졌다가 제목 줄만 남기고 접힙니다.
- **횃불 자동 사용**: **암흑(0)** 을 선택한 경우, 원정이 끝나면 암흑을 선택하기 전 설정으로 돌아갑니다.
- 일부 UI를 조정했습니다.

### 버그 수정

- 일부 버그를 수정했습니다.

## [1.3.0] - 2026-10-30

### 새 기능

- **원정대 · 장신구 프리셋**: 원정 선택 화면 명단 첫 줄 옆 화살표 버튼. 모드 영웅 · 장신구 칸 늘림 모드 자동 대응. 권장 순서: 원정 선택 → 원정대 프리셋 → 장신구 프리셋
- **무작위 원정대 편성**: 주사위 버튼
- **원정대 조합 목록**: 조합별 달성 여부
- **턴 순서**: 확정 순서 ↔ 예상 확률 전환(속도 + 1d8 의 모든 경우의 수로 계산)

### 개선

- **스톨링 카운터**: 고른 기술이 증원 방지인지 증원 유발인지 표시
- **오버레이 모드**: 세이브 로드 시 자동 전환(별도 창 모드로 수동 전환 가능), 원정 중 요소별 켜기 · 끄기 · 사이드 패널 접기
- 수정된 게임 실행 파일 인식
- 알림 문구 개선.

### 버그 수정

- 일부 버그 수정.

## [1.1.3] - 2026-10-23

### 개선

- 전투 화면 가운데 표시 위에 지금 고른 기술의 이름과 아이콘이 나옵니다.
- 아군을 밀거나 당기는 기술도 대상 머리 위에서 이동 확률과 도착할 열을 볼 수 있습니다.
- 횃불 자동 사용: 밝기 단계에 마우스를 올리면 그 단계의 보정이 보입니다.

### 버그 수정

- 영웅 표에 사망한 영웅이 남아 있던 문제
- 핏빛 저주에 걸린 영웅에게 질병 확률이 뜨던 문제(다른 질병에 걸리지 않으므로 0%로 표시)
- 전투 중 차례가 넘어갈 때 화면이 버벅이던 문제
- 적 행동 예측 등 일부 계산식을 게임과 동일하게 수정

## [1.1.2] - 2026-10-21

### 새 기능

- 반격 미리보기: 전투 화면에서 반격하는 대상의 공격 수치 아래에 반격 피해와 명중·치명타 확률, 효과를 보여 줍니다. 공격 연출 동안에도 수치가 그대로 남습니다.
- 횃불 자동 사용: 밝기 정보 위 줄에서 단계를 고르면, 탐험 중 밝기가 그 아래로 떨어질 때 앱이 대신 횃불을 씁니다. 암흑(0)을 고르면 전투 중에도 밝기를 0으로 유지합니다.
- 야영 중 야습 확률 안내: 야영 중엔 정찰 줄 자리에 야습 확률을 보여 줍니다. 방패 파괴자 등의 회상 전투가 예정돼 있으면 그것을 대신 알려 줍니다.

### 개선

- 사용자가 고른 설정을 저장합니다.

### 버그 수정

- 일부 계산식을 게임과 동일하게 수정

## [1.1.0] - 2026-10-17

### 새 기능

- 전투 화면: 전투 중엔 지도 자리에 전투 화면이 뜹니다. 고른 기술의 대상별 피해량과 명중·치명타·효과 확률, 적이 고른 기술과 대상, 상태의 남은 턴과 지속 피해를 보여 줍니다.
- 카드에서 바로 선택: 골동품과 장애물, 허기짐 카드의 줄을 누르면 게임에서 그 선택지를 실행합니다.
- 함정: 정찰된 함정 앞에서 자동으로 멈추고, 함정 카드에서 영웅을 골라 해제합니다.
- 소지품 정리 · 판매가: 탐험 중 [I] 키로 소지품을 정리하고, 앱의 가방 아이콘에 마우스를 올리면 판매가가 뜹니다.
- 전투가 끝나면 기본 원정대 설정으로 자동 복귀합니다(원정대 버튼으로 켜고 끄기).

### 개선

- 화면 안내를 새로 만들었습니다.

### 버그 수정

- 장신구 · 기벽 강화 수치가 게임과 다르게 보이던 문제
- 게임 문구에서 색이 지정된 낱말이 색 없이 보이던 문제
- 모드 문구가 다른 언어로 보이던 문제

## [1.0.8] - 2026-10-12

### 새 기능

- 보급품 자동 구매: 추천 표의 줄을 두 번 누르면 앱이 상점을 대신 눌러 추천 수량에 맞춰 삽니다. 이미 더 가지고 있으면 남는 만큼만 되팔고, 영웅이 무료로 준 보급품은 건드리지 않으며, 끝나면 상점 순서로 칸을 정리합니다. 크림슨 코트에서는 원정대의 핏빛 저주 영웅 수에 맞춰 피도 챙깁니다(저주 영웅 1명당 짧음 1 · 중간 2 · 긺 3 · 기진맥진 4개). 마을에서 대기 중인 영웅에게 필요한 피는 영지에 남깁니다.

### 개선

- 보급품 추천 표가 안뜰+, 농장+, 태양을 향한 섬들, 버민타이드, 악마의 축제 모드를 지원합니다. 해당 모드를 켰을 때만 나옵니다. (모드의 던전 생성 규칙과 골동품 등장 가중치를 바탕으로 계산한 추정치라 실제와 다를 수 있습니다.)
- 보급품 구입 화면에서 고른 퀘스트의 줄이 강조되고, 그 던전이 표 맨 위로 올라옵니다.

### 버그 수정

- 디버그 모드 F6(스트레스 0)이 미터기에서 스트레스 해소로 잡히던 문제
- 모드 직업의 일부 기술 아이콘이 안 보이던 문제
- 일부 영웅 그림(석궁사수, 방패파괴자) 옆에 빈 공간이 크게 남던 문제

## [1.0.7] - 2026-10-09

### 새 기능

- 게임이 알려주지 않는 정보를 끌 수 있습니다. 지도 아래 줄의 전투와 허기짐 아이콘을 누르세요.
  - 전투: 아직 가 보지 않은 칸의 특수 인카운터 위치와 적 구성
  - 허기짐: 지도의 허기짐 칸
  - 탐색한 곳만 보기와 따로 적용되고, 끈 상태는 다음 실행에도 유지됩니다.

## [1.0.6] - 2026-10-07

### 새 기능

- 마을에서 원정대 누적 미터기를 볼 수 있습니다(이번 업데이트 이후 원정부터 기록).
- 영웅 표에서 초상에 마우스를 올리면 영웅의 모습과 장비 레벨, 전투 기술 레벨, 야영 기술을 볼 수 있습니다.

### 개선

- 원정이 끝나면 원정 기록 맨 아래에서 최종 미터기를 확인할 수 있습니다.

## [1.0.5] - 2026-10-05

### 개선

- 제단에서 소환한 기는 혼돈이 지도에 기는 혼돈 마커로 표시됩니다.

### 버그 수정

- 원정 중 일부 영웅이 사망한 뒤 전투 카드가 표시되지 않던 문제를 고쳤습니다.

## [1.0.4] - 2026-10-05

### 버그 수정

- 새 캠페인 초반에 전투 막대에서 영웅 하나가 빠지던 문제를 고쳤습니다(튜토리얼의 디스마스 등).

## [1.0.3] - 2026-10-05

### 새 기능

- **앱 지도에서 방 이동**: 이어진 방을 클릭하면 게임에서 그 방으로 이동합니다.
- **장애물 카드**: 장애물을 조사하면 맨손으로 지나갈 때의 대가와 치우는 데 필요한 보급품을 보여 줍니다.

### 버그 수정

- **원정 미터기 정확도 개선**
  - 반격 피해와 처치가 반격한 영웅에게 집계됩니다.
  - 출혈과 중독, 화상 피해와 처치를 해당 효과를 건 영웅의 기록으로 집계합니다. 들불과 통제된 화상으로 붙은 화상도 포함됩니다.
  - 지속 회복량은 그 효과를 건 영웅의 회복량으로 집계합니다. 복도를 걸을 때 받는 회복도 셉니다.
  - 마지막 적을 쓰러뜨린 막타가 가끔 빠지던 문제를 고쳤습니다.
- 모드로 추가된 조우의 적 구성이 지도에 표시되지 않던 문제를 고쳤습니다.

## [1.0.2] - 2026-10-04

### 새 기능

- **새 버전 알림** — 앱을 켤 때 이 저장소의 최신 릴리스를 확인해, 새 버전이 있으면 안내 창을 띄웁니다. 왼쪽 위 서명을 누르면 앱 정보와 업데이트 확인 버튼이 나옵니다. 자동으로 내려받거나 교체하지는 않습니다.
- **화면 안내** — 오른쪽 위 물음표(?) 버튼으로 각 화면을 단계별로 설명합니다.

### 버그 수정

- 그 밖에 전투 카드의 밝기 보정과 미터기 집계 정확도 등 여러 문제를 수정했습니다.
